# Contributing

The public repository contains the skill, document core and collection/check/transfer tools. Crescreendo's hosted editor and cloud services are private and are not prerequisites for building these packages.

Report the host/OS and package version, exact failed step, and a minimal reproduction with assets you can share. Remove private app data, signed URLs, OAuth tokens and upload tickets. For visual differences, include equally sized source/output crops and distinguish fidelity from editability.

Prefer a demonstrated general behavior fix over a rule for a named app or frame number. Preserve source order and record inferred/generated content. Use fixtures and protocol checks rather than paid model calls for routine validation.

The skill, core and tools use the [MIT license](LICENSE). Asset licenses are separate. Original examples include provenance; the Inter example retains its OFL notice. Do not contribute third-party captures or models without appropriate permission.
