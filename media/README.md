GIFs are 25 fps, edited from continuous 30 fps browser-tab recordings. Waiting and the native file chooser are cut; **Time compressed** is visible in each clip. Crops enlarge real UI. No selection outlines, editor controls or pointers were drawn onto the recordings. A 25 fps file alone is not evidence of 25 unique movement frames per second; the recorder emits variable-rate frames while the screen is idle.

The separate full-set server-render attempt timed out and was canceled. The successful PNG export in this media set came from the browser editor. These are Development demonstrations, not evidence that the public Cloud release is available.

The mobile screens inside the mockups are authored Crescreendo concept artwork, not a shipped mobile app. The outer editor UI is real. The headline “Your app. In seconds.” is demo copy, not a measured completion-time claim. Laurel and stars are decoration, not a rating claim.

X's App Store artwork is a comparative reference, not an endorsement or MIT-licensed project asset. These derivatives do not include a downloadable X template, original source files, fonts, GLBs or private project archives. Public-use clearance remains separate from this local media preparation.

File hashes, dimensions, frame timing and verification scope are recorded in [provenance.json](provenance.json). See the [case study](../docs/x-case-study.md) for editability and fidelity limits, and the [capture brief](../docs/demo.md) for replacement requirements.
